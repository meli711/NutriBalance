## Eigene Fotos ergänzen

Platz für Melianes eigene Food-Fotos. Einfach hier ablegen und sinnvoll
benennen (z.B. `rezept-<recipe-id>.jpg` für ein Foto zu einem bestimmten
Rezept, oder `hero-<anlass>.jpg` für weitere Header-Bilder). Empfehlung für
die Matura-Arbeit: möglichst komprimiert (JPEG, ~1000px Breite reicht für
Mobile/Desktop) und mit kurzer Bildunterschrift inkl. Aufnahmedatum, falls
das für die Quellenangabe relevant ist.
